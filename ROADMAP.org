* Development gates

Run =make test=, =make sandbox-test=, =make test-isolation= and =make lint=.
The separate =make offline-test= runs actual dependencies with loopback HTTP
and fixture CLI executables. CI requires Emacs 29.1/30.2 and minimum/current
gptel workflow jobs; snapshot remains an early-warning job.

Live provider credentials, provider CLI installations, model entitlement,
unattended execution outside Emacs, performance benchmarks and coverage
percentages are separate proof boundaries. The offline catalog needs none
of them. Follow [[file:specs/armory-parity.org][Armory parity]] for intentional non-goals.
