#+title: Passage feedback and Org TODO delegation — native verification
#+date: 2026-10-10

* Delivered behavior

The user selected two improvements: comment on the work and revise related
feedback together; delegate an Org TODO and return to its patch and checks.
[[file:../../work-review.org][The user guide]] documents keys, storage, provider configuration, and recovery.

Passage comments persist as readable Org with exact source text and optional
proposed drafts. Batch responses must match every comment ID and exact live
anchor before any replacement is offered. Acceptance uses existing edit
proposal hooks and protects accepted text. Rejection reopens feedback.
Restored feedback reopens when its in-memory proposal no longer exists.

TODO runs use the existing Armory runner with an explicit detached workspace.
The snapshot includes tracked disk edits while preserving the user's index.
Agent completion and explicit asynchronous checks have separate states.
The source heading exposes the task's patch and actual check output without
stealing focus. Hunk feedback persists and travels with a subsequent revision.
Applying the reviewed patch checks current disk content and affected unsaved
buffers; completion and application leave the Org TODO state unchanged.

The saved source fingerprint intentionally precedes the commit that contains
the evidence, avoiding a circular commit-hash claim.

* Practical limits

Normal model runs still require the user's configured provider. The owned
fixtures prove execution and review behavior, not the usefulness of a model's
revision. Initial task snapshots exclude untracked files; save project buffers
before dispatch. Checks run only when explicitly configured. Applying reviews
the complete task patch. Worktrees are retained for inspection and not deleted
automatically. Finished records reopen across restarts; interrupted processes
are not automatically resumed. Save source Org files to retain heading links
and accepted document changes across restarts.
